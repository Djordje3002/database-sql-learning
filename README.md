# Database SQL Learning

Mesto za učenje SQL-a kroz kratke, praktične primere. Svaki novi zadatak dodajemo kao poseban primer uz objašnjenje.

## Struktura

- `sql/01-osnove.sql` — osnovni `SELECT`, filtriranje, sortiranje i agregacije.
- `sql/02-join-i-agregacije.sql` — spajanje tabela i brojanje knjiga po izdavaču.

## Pokretanje primera

Primeri su pisani u standardnom SQL-u i mogu se prilagoditi za PostgreSQL, MySQL ili SQLite. Svaka datoteka sadrži komentare koji objašnjavaju upit.

## Plan

1. `SELECT`, `WHERE`, `ORDER BY`
2. Agregatne funkcije i `GROUP BY`
3. `JOIN`
4. Podupiti, CTE i prozorske funkcije
5. Dizajn tabela, indeksi i optimizacija
