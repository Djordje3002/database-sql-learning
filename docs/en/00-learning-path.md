# Learning path

> **English** · [Srpski](../00-plan-ucenja.md)

## Goal

Learn to read, connect, change, and model relational data independently — then understand how to keep a query fast and safe.

## Sequence

1. **Core queries** — `SELECT`, `FROM`, `WHERE`, `ORDER BY`, `LIMIT`, and `DISTINCT`.
2. **Values and conditions** — comparisons, `AND`, `OR`, `IN`, `BETWEEN`, `LIKE`, and `NULL`.
3. **Functions and summaries** — text and number functions, `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, and `HAVING`.
4. **Multiple tables** — primary and foreign keys, `INNER JOIN`, and `LEFT JOIN`.
5. **Expressive queries** — subqueries, CTEs, `CASE`, set operations, and window functions.
6. **Changing data** — `INSERT`, `UPDATE`, `DELETE`, transactions, and safety.
7. **Design** — types, constraints, normalization, indexes, and execution plans.

## How to practise

- Read a small theory section, then run every query by hand.
- Predict the output before you look at it.
- Change one part of a query and observe what changes.
- Save each new exercise and solution in the next numbered lesson.

The aim is not to memorize syntax. The aim is to know **which question you are asking the data** and write a dependable answer.
