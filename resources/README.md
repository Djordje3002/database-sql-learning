# Pomoćni materijali

[Srpski](README.md) | [English](en/README.md)

Ovaj folder sadrži kratke, ponovljive materijale koji pomažu dok radiš kurs. Nije zamena za lekcije u `docs/` niti za upite u `sql/`: ovde se brzo podsećaš na sintaksu, tok rada i pravila kvaliteta.

| Materijal | Kada ga koristiš |
| --- | --- |
| [SQL Cheat Sheet](cheat-sheet.md) | Kada znaš šta želiš da uradiš, ali želiš brz podsetnik na oblik upita. |
| [Pravila za doprinos](../CONTRIBUTING.md) | Pre dodavanja nove lekcije, zadatka, rešenja ili primera. |

Za sistematično učenje kreni od [plana učenja](../docs/00-plan-ucenja.md), a za pokretanje primera od [pripreme baze](../sql/00-priprema-baze.sql).
