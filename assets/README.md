# Course visuals

This directory contains original visual assets used by the course.

| Asset | Used in | Description |
| --- | --- | --- |
| `database-learning-hero.png` | root README | connected relational tables, representing the foundation curriculum |
| `advanced-query-optimization.png` | Advanced Database Course | abstract data flow, execution plan, and result grid |

The illustrations intentionally contain no embedded wording, branding, or labels so the course remains equally usable in Serbian and English.
